02 / Moat vs. Execution speed

Core Value Engines

Compounding Moat

Every verified profile, successful placement, and peer trust signal increases the dataset's lock-in. A two-sided campus trust graph takes years of relationships to build and is highly defensible once established.

Network effects Data compounds High switching cost
Execution Speed

Focuses on absolute utility from day one with zero network density dependencies. The infrastructure stack (NanoBot VMs) is technically open source, but offsets lock-in with warm B2B pipeline conversion.

03 / Risk Profiles

Strategic Risk Spectrum

Venture Moonshot Bootstrapped SaaS
Hiring Platform (25%)
Agent Platform (75%)

Idea A requires solving a cold-start problem. It faces strict NYC/Colorado automated decision laws and transactional fee volatility. In exchange, it is highly fundable and structurally protected against LinkedIn (who cannot deploy auto-matching without cannibalizing 70% of search friction revenue).

Idea B requires zero capital and provides predictable SaaS cash flow. It operates with minimal regulatory friction. In exchange, it faces platform risk as Apple, Google, and OpenAI deploy free, native task agents, requiring us to defend a narrow B2B vertical niche.

04 / Roadmaps

Staged Implementation Paths

Idea A / Hiring Platform

Weeks 1–4

Develop conversational candidate profile builder. Agents scan public Vanderbilt career center feeds. No users required to deliver day one value.

Weeks 5–8

Wizard of Oz concierge launch. Founders match Vanderbilt candidates to employers manually and collect first high-ticket placement fees.

Weeks 9–12

Deploy automated self-serve employer dashboard. Launch natural-language candidate searches and automated reference checking products.

Months 3–6

Integrate ATS APIs (Greenhouse, Ashby). Implement peer-to-peer trust graph ratings and transition transaction fees to SaaS.

Idea B / Agent Platform

Weeks 1–4

Package NanoBot runtime on isolated scale-to-zero microVM environments. Establish Claude API routing. Curate 10 core skills.

Weeks 5–8

Develop conversational onboarding matching personas to capabilities. Construct smart Ledger and plain-English Skill Marketplace.

Weeks 9–12

Beta test with existing NULLPOINT SMB clients. Transition episodic engineering consulting projects to compounding $200/mo managed infrastructure plans.

Methodology Trade-offs:
• Idea A allows a highly manual concierge wedge to validate matching rules instantly, pushing back the automated product build.
• Idea B requires building container vm infrastructure upfront before first dollar, but establishes a highly automated, low-touch delivery system from day one.
